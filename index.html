Cómo deployar a Netlify

Opción A (más simple, 30 segundos): Ir a https://app.netlify.com/drop, arrastrar este archivo HTML, y listo. Tenés URL al instante.

Opción B (con tu GitHub, auto-deploy): Subir el archivo a un repo (ej. git add . && git commit -m "init" && git push), entrar a app.netlify.com, conectar el repo, y cada push deploya solo.

Importante sobre los datos: el auto-save usa localStorage, que vive en cada navegador por separado. Si querés sincronizar entre dispositivos, exportá JSON desde uno e importalo en el otro.
