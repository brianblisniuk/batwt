## Notas para Comercial

- **Dos líneas de producto bien diferenciadas** listas para replicar:
  - *Motorhome + deporte* (EE.UU. / Mundial): ticket alto, logística intensiva, fuerte componente experiencial de ruta.
  - *Gastronómico-enológico premium* (Italia / Argentina): villa o 5★, estrellas Michelin, bodegas icónicas, accesos exclusivos vía red de winemakers.
- **El viaje Rudoni** es el primer cliente **externo** (los demás son propios / piloto) — sirve como caso de referencia vendible para el segmento familiar Mundial.
- **Los viajes en planning** (Piemonte, Argentina BA/Mendoza) están con itinerario cerrado a nivel experiencia; faltan confirmaciones de proveedores. Útiles como plantilla de propuesta inmediata.
- Itinerarios disponibles con mayor detalle operativo (proveedores, contactos, reservas) en la herramienta interna si comercial necesita armar una cotización.

> Puedo agregar a este documento, si lo necesitan: **presupuesto / pricing por viaje**, **listado de proveedores y partners**, o una **versión one-pager por viaje** lista para enviar a un prospecto. Avisame.
